# mj-llm 제품 기획서

> 기준: 2026-10-08. 기존 `mj_llm_wapper`의 진행 중인 기획·설계를 계승한 독립 제품이다.
> 현재 상태는 설계와 N0 macOS CPU 추론 probe 구현이며, 아래 요구사항은 제품 구현 완료 목록이 아니다. 실제 검증 범위는 [N0 기록](n0-feasibility.md)을 따른다.

## 목표

Ollama/Python 별도 설치 없이 PC·Android·iOS에서 자료를 검색하고 근거를 보며 대화한다.
공통 코어와 플랫폼별 앱으로 개발하며 모든 기기에 동일한 바이너리를 쓰는 것은 아니다.

장치에 맞는 모델을 고르고 설치하는 기존 허브의 흐름을 유지하면서, 개인 자료의 검색과 근거 기반 대화까지 하나의 앱으로 제공한다. 사용자는 엔진 서버를 구성하거나 개발 도구를 설치할 필요가 없어야 한다.

## 사용자와 해결할 문제

- 개인 사용자·연구자: 문서와 사진을 외부로 보내지 않고 자연어로 찾고 근거를 확인한다.
- 로컬 AI 사용자: 모델 파일 크기와 실제 메모리 요구량을 구분하고, 자기 기기에서 검증된 모델을 설치한다.
- 개발자: 후속 선택형 로컬 API로 같은 실행 계약을 사용한다. 기존 Narmer 연동 요구는 호환성 검증 자료로 계승한다.

## 필수 플랫폼과 지원의 의미

Windows, macOS, Linux, Android, iOS/iPadOS 설치형 앱을 필수 제품 대상으로 한다. 휴대폰뿐 아니라 Android 태블릿과 iPad의 화면·파일 선택·앱 복귀도 검증한다. 브라우저 단독 실행은 현재 후속 후보라는 가정이며, PC 웹 기술 기반 UI와 브라우저 안의 독립 추론은 구분한다.

| 대상 | 첫 공통 출시의 기준 조합 | 추가 검증 대상 |
|---|---|---|
| Windows | x86_64 | ARM64 |
| macOS | Apple Silicon arm64 | Intel x86_64 |
| Linux | x86_64, N0에서 고정할 기준 배포판 | arm64·다른 배포판 |
| Android | arm64, 휴대폰·태블릿 | 추가 제조사·가속기 조합 |
| iOS/iPadOS | arm64, iPhone·iPad | 추가 기기 세대 |

아키텍처별 우선순위는 설계 기본값이다. 최소 OS·RAM·저장공간과 Linux 배포판은 N0에서 실측해 고정한다. 모든 OS를 지원한다는 요구가 모든 구형 기기·CPU·모델을 보장한다는 뜻은 아니다. 추가 조합은 미검증으로 표시하고 정식 지원으로 광고하지 않는다.

각 필수 플랫폼은 모델 준비 후 다른 PC·서버·클라우드 연결 없이 자료 추가, 문서·사진 검색, 텍스트 근거 대화, 저장과 복구를 수행해야 한다. 사진의 의미 검색은 필수이며 사진 내용으로 답변을 만드는 기능은 생성 모델의 vision 또는 실제 OCR/캡션 유무를 표시한다. 동일 모델·속도·가속기의 일치를 요구하지 않지만 기능 제한은 설치 전에 안내한다.

## 첫 출시의 기본 가정

- 개인용, 로컬 우선, 한국어 검색 품질 우선 검증
- PDF·Markdown·TXT·사진 추가와 증분 색인
- 의미 검색 결과에서 원본 페이지·사진 열기
- 검색 근거에 기반한 대화와 유효한 출처 표시
- 플랫폼별 검색 모델 1개와 생성 모델 1개 검증
- 네트워크 없이 사용, 취소·앱 종료·재시작 복구

## 기능 우선순위와 수용 기준

| ID | 요구사항 | 완료 증거 | 단계 |
|---|---|---|---|
| P01 | 독립 설치·기기 진단·검증 패키지 추천 | Ollama/Python 없는 환경에서 설치하고 부적합 모델 차단 사유 표시 | N0~N2 |
| P02 | 모델 다운로드·재개·로컬 import·해시 검증·삭제 | 중단 다운로드 복구, 손상 파일 실행 차단, 사용 중 삭제 보류 | N1~N2 |
| P03 | 프로젝트와 PDF/Markdown/TXT/사진 관리 | 권한 취소·손상 자료를 개별 처리하고 성공/보류/실패 수 표시 | N1~N2 |
| P04 | 증분 색인과 의미·키워드 검색 | 자료별 원본 위치 이동, 삭제 즉시 제외, 다른 프로젝트 노출 0건 | N1~N2 |
| P05 | 일반 대화와 근거 기반 스트리밍 대화 | 중지·부분 응답 저장·재시작 복원, 인용 위치 검증 | N1~N2 |
| P06 | 메모리·열·lifecycle 보호 | 실기기 반복 질의, 강제 종료 후 checkpoint 복구 | N0~N2 |
| P07 | 기존 JSON 대화 가져오기 | 사용자가 고른 파일만 import, 중복·손상·실패 rollback 검증 | N1 |
| P08 | 선택형 개발자 API | 로컬 인증, capability·오류·stream/non-stream conformance | N4 |
| P09 | 음성·영상 검색과 시간 위치 인용 | 별도 modality·코덱·시간 정합성 평가 | N3 |
| P10 | MCP·추가 모델·신뢰 노드·프로젝트 이동 | 기능별 보안·호환성 gate 이후 제공 | N4 |

대화 이름 변경·삭제는 기본 관리에 포함한다. 메시지 분기, 대화 전문 검색, Quick RAG, 고급 세션 프로필, Model Lab/Project Arena, 자동 agent 실행은 확장 backlog로 보존하며 첫 공통 출시의 필수 기능에 넣지 않는다.

## 주요 화면과 사용자 흐름

1. **시작·모델 센터:** 기기 진단 → 검증된 검색/생성 패키지 추천 → 용량·라이선스 확인 → 설치 또는 로컬 가져오기. 측정 전 예상치와 해당 기기 실측값을 구분한다.
2. **프로젝트·자료:** 프로젝트 생성 → 파일·사진 선택 → 색인 진행·취소·재개 → 실패 자료만 재시도한다.
3. **검색:** 자연어 검색 → 문서 페이지·사진 결과 → 원본 열기 → 선택한 근거로 질문한다.
4. **대화:** 일반 대화와 프로젝트 근거 대화를 구분한다. 토큰·출처·중지·부분 응답 상태를 보여준다. 근거가 없으면 부족함을 알린다.
5. **설정·장치:** 모델과 자료의 저장공간, 실행 가능 기능, 검증 상태, 로컬 데이터 삭제를 제공한다.

PC는 키보드와 넓은 화면, 모바일은 터치와 OS 파일/사진 선택기를 사용한다. 화면 낭독 레이블·글자 크기 변경·키보드 탐색·상태의 텍스트 표현을 공통 UX 기준으로 삼는다. 휴대폰 UI를 늘리는 것만으로 태블릿 검증을 대신하지 않는다.

## 후속 범위

음성·영상 구간 검색, 원본 시간 위치 재생, 추가 모델, MCP, 선택형 신뢰 노드 및 프로젝트 이동.

기존 Qwen/Gemma/DeepSeek/Mistral/Phi/gpt-oss 모델군은 확장 평가 목록으로 계승한다. 과거 Ollama tag·카탈로그 등록·다른 엔진의 실행 성공을 native 지원 증거로 쓰지 않는다. 플랫폼별 artifact와 생성/embedding capability를 별도로 검증한다. MLX는 macOS 전용 adapter 후보이며 공통 코어의 필수 의존성이 아니다.

## 제외

초기 모델 학습·파인튜닝, 음성·영상 생성, 자동 클라우드 전송, 자동 기기 동기화,
모든 Hugging Face 모델의 자동 변환, 모바일에서 대형 모델 실행 보장.

## 완료 기준

Ollama/Python 미설치 환경의 PC 3 OS와 Android/iOS 실기기에서 기본 검색·대화 흐름을 검증한다.
정확한 최소 OS·장치, SDK/artifact 버전과 성능 예산은 N0 실측으로 확정한다.
자세한 계약과 검증 gate는 [아키텍처](architecture.md)를 따른다.

N1은 PC 미리보기이며 첫 공통 정식 출시는 N2다. 필수 플랫폼 하나라도 gate를 통과하지 못하면 전체 플랫폼 출시 완료로 표시하지 않는다. 한국어 검색 Recall@5·지연·메모리 목표와 평가 fixture는 아키텍처 11장을 따른다. 품질·성능 수치는 달성 결과가 아닌 목표다.

## 남은 결정

- 브라우저 단독 실행의 출시 시점과 별도 저장소·권한·오프라인 정책
- 최소 OS·기기·Linux 배포판, 추가 CPU 아키텍처의 정식 지원 시점
- 첫 생성 모델, 고정 SDK/artifact, 배포 형식과 채널
- 확장 기능의 순서와 자동 동기화 필요성

미정 항목은 기본 가정을 명시해 진행하되, 실측 실패를 이유로 필수 플랫폼을 조용히 제외하거나 원격 실행으로 대체하지 않는다.

# mj-llm 제품 범위

## 목표

Ollama/Python 별도 설치 없이 PC·Android·iOS에서 자료를 검색하고 근거를 보며 대화한다.
공통 코어와 플랫폼별 앱으로 개발하며 모든 기기에 동일한 바이너리를 쓰는 것은 아니다.

## 첫 출시의 기본 가정

- 개인용, 로컬 우선, 한국어 검색 품질 우선 검증
- PDF·Markdown·TXT·사진 추가와 증분 색인
- 의미 검색 결과에서 원본 페이지·사진 열기
- 검색 근거에 기반한 대화와 유효한 출처 표시
- 플랫폼별 검색 모델 1개와 생성 모델 1개 검증
- 네트워크 없이 사용, 취소·앱 종료·재시작 복구

## 후속 범위

음성·영상 구간 검색, 원본 시간 위치 재생, 추가 모델, MCP, 선택형 신뢰 노드 및 프로젝트 이동.

## 제외

초기 모델 학습·파인튜닝, 음성·영상 생성, 자동 클라우드 전송, 자동 기기 동기화,
모든 Hugging Face 모델의 자동 변환, 모바일에서 대형 모델 실행 보장.

## 완료 기준

Ollama/Python 미설치 환경의 PC 3 OS와 Android/iOS 실기기에서 기본 검색·대화 흐름을 검증한다.
정확한 최소 OS·장치, SDK/artifact 버전과 성능 예산은 N0 실측으로 확정한다.
자세한 계약과 검증 gate는 [아키텍처](architecture.md)를 따른다.
